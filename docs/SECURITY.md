# 安全边界

核心消费调用者提供的 Bytes，不读取网络、环境或时钟，不写文件。字段值保留在模型中；默认报告仅展示结构、长度和源位置。`--show-values --json` 才显式展示逻辑值，使用者应选择安全的输出位置。

| 数据流与威胁 | 缓解 |
|---|---|
| 伪造版本、篡改服务字符 | UNA 字符互异、版本/字符集门禁，未知配置拒绝 |
| 不可信长度、计数和大量诊断造成拒绝服务 | 输入和各级数量预算；六位计数先验证再算术；诊断耗尽停止 |
| 业务值进入错误和日志 | 稳定静态解释，不拼接字段值；默认 JSON 不输出 value 或引用 |
| 路径与 native FFI 边界 | 路径 UTF-8 显式转换、拒绝 NUL、只读打开普通文件、校验缓冲区读长 |
| 文件增大或替换 | 同一打开句柄做大小/类型检查，分块读取且总量最多预算加一个探测字节 |
| 文件句柄泄漏或越权修改 | 每个返回路径关闭句柄，适配层无文件写入函数 |
| 误把检查结果当交易授权 | 语法与封套分层；rules 固定 not_checked，不产生自动交易或回执 |

没有第三方 Mooncakes 依赖，使用工具链自带 core 和系统 C 库。资源预算限制处理规模，不承诺任意配置下不会耗尽机器内存；调用者应给出适合环境的上限。版本 0.1.0 是整份文件解析，模型和报告占用随输入增长。支持子集及部署边界见 SYNTAX_PROFILES.md。
