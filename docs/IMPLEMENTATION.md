# 初验实施清单

用户已于 2026-10-11 授权按 `goal.md` 完成初验，每个小目标单独提交，所有操作留在本地，不 push。采用推荐的 parser + lib、Bytes 输入、native/JS/wasm-gc 核心及 native CLI；已有包名与 Apache-2.0 许可证沿用脚手架。

| 小目标 | 验收方式 |
|---|---|
| T0 设计和骨架 | 工具链检查、构建、需求决策 |
| T1 服务字符和语法配置 | 默认/自定义 UNA、版本和字符集、非法服务字符 |
| T2 通用结构解析 | release、空值、原始字节范围、截断段 |
| T3 封套校验 | 直接多消息、存在/顺序、计数、引用 |
| T4 限额和安全诊断 | 每种资源上限、稳定代码、JSON 默认脱敏 |
| T5 native CLI | inspect/validate、用法、I/O、退出码、文件限额 |
| T6 五个示例和语料 | 公共 API 消费、库与 CLI 结果一致 |
| T7 回归与 CI | 至少 60 用例、20 畸形、5 端到端，三后端构建/测试、独立消费项目 |
| T8 文档和本地发布准备 | 公共使用文档、来源/许可/AI 记录、干净源码验证、源码包检查、初验清单 |

核心代码按 `model / syntax / lexer / envelope / report` 文件组织在一个库包，CLI 独立包只调用公共 API。测试按语法、扫描、封套、限额、报告分类，名称使用 `valid/`、`invalid/`、`edge/`；新行为先用失败测试定义。所有语料自行合成，无交易数据或业务目录。

本地完成后，公开 Git 仓库、远程 CI、Mooncakes 发布与从注册表安装仍需维护者执行。另做离线干净消费项目验证；不以它替代注册表安装证明。
